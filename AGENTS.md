# AGENTS.md

This repository follows `ttomohisa/htmlapps-template`. Keep the app as a single distributable HTML file. Preserve local-only processing and `connect-src 'none'`. Do not replace embedded runtime/model assets with CDN dependencies. Keep mobile usability, manual-mask fallback, and the pre-save review reminder when changing the UI.

Before committing, run `build-standalone.bat` and `scripts\check-repository.ps1`.
